# 📊 Customer Churn Analysis

An end-to-end Python data analysis project focused on understanding customer churn patterns, identifying key drivers behind customer attrition, and providing actionable retention strategies.

## 📌 Project Overview
Customer churn is a critical metric for business growth and retention. This project analyzes customer demographic, usage, and subscription data to determine churn rates across different segments and states.

### Key Objectives:
- Analyze churn rate across state/location types and subscription categories.
- Identify core factors contributing to customer drop-off.
- Clean and process raw database records into structured summary outputs.

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Database:** SQLite (`customer_churn.db`)
- **Environment:** Jupyter Notebook / JupyterLab
